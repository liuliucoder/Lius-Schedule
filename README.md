# Lius-Schedule
> 个人练手软件，一个运行在安卓端的本地课程表 App，欢迎体验！

## 项目简介
这是一个基于 H5 开发的轻量级本地课程表应用，借助 HBuilderX 打包成安卓 App。支持文本一键导入课程，自动计算周次和日期，完全离线运行，不收集任何个人数据。

## 功能特性
- **智能导入**：支持各种括号格式，自动识别“课程”、“教师”、“教室”等关键词。
- **周次适配**：完美支持单双周、指定周次（如6-12周、16-19周）。
- **自定义作息**：可自由设置每天节数和每节课的上下课时间。
- **简洁界面**：采用极简设计，支持今日课程、总课表、导入三大模块。
- **本地存储**：数据保存在手机本地，无需联网，安全可靠。

## 技术栈
- **前端**：HTML5, CSS3, JavaScript (原生)
- **打包工具**：HBuilderX (5+App)
- **数据解析**：SheetJS (xlsx.full.min.js)

## 如何安装
1. 下载并安装 APK 文件（需在安卓手机上允许“未知来源应用”安装）。
2. 首次打开后，进入“导入课程”页面，粘贴课表文本或导入 Excel 文件。
3. 设置好开学日期和作息时间，即可使用。
